## Build a Stock Tracker

This REPO has some examples of what the completed tasks could look like including:

- Fetching the past data for a chosen asset(s)
- Displaying the data on a chart
- Fetching live data for an asset
- Displaying the live data on a chart
- Displaying multiple graphs
- Displaying multiple streams
